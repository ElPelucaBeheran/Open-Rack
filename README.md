# Open-Rack

![Open Rack Preview](images/preview.png)

Open Rack is a custom **300mm rack system** that uses simple, easy-to-remember measurements.  
It is designed to use **M4 screws only**, allowing hardware to be mounted without the need for nuts.

---

## 📦 System Overview

![Full Unit](images/full-unit.png)

![Full Unit IRL](images/IRL/total-assembly.png)

The system is made out of **two different units**:

---

### 🔲 Full Unit (300mm wide)

![300 Unit RACK](images/300-unit.png)
![300 Unit RACK IRL](images/IRL/full-u.png)

**Measurements**  
- **RACK**
-- ![Full Unit RACK Diagram](images/300-u-diagram.png)
  
  
- **UNIT**
-- ![Full Unit Diagram](images/full-u-diagram.png)
This unit allows you to:
- Fit **M-ATX motherboards**
- Mount up to **2 × 3.5"/2,5" SATA hard drives by bay**

---

### 🔳 Half Unit (150mm wide)

![Half Unit](images/half-unit.png)
![Half Unit IRL](images/IRL/half-u.png)

**Measurements**  
- **RACK**
![Half Unit](images/half-udiagram.png)


- **UNIT**
![Half Full Unit Diagram](images/half-u-diagram.png)
This unit is designed to house:
- **Single-board computers** (e.g. Raspberry Pi)
- Smaller components such as:
  - ATX power supplies
  - I2C LCD modules
  - Networking equipment

## 🔗 Pre-Made Modules

### 🖥️ M-ATX Board
![matx board](images/M-ATX-Board.png)
![matx board IRL](images/IRL/matx-frontview.png)

**Needs Bronze Standoffs**

#### Hardware

- M4 Nut ×3  
- M4 × 20 mm Screw ×3  
- M4 × 10 mm Screw ×4
- Bronze Standoff x6

This Module is 5U tall (75mm tall) and supports motherboards up to 55mm tall

### 💾 Disk Bays
![2,5"bay IRL](images/IRL/2,5-3,5-bays.png)
#### 2,5" Disk Bays
![2,5"bay](images/2,5-Disk-Bays.png)
#### Hardware  
- M4 × 10 mm Screw ×4

#### 3,5" Disk Bays
![3,5"bay](images/3,5-Disk-Bays.png)

### ⚡M-ATX Power Supply Plate
![matx power supply](images/M-ATX-Power-Supply.png)
